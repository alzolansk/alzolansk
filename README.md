# João Alencar

Estudo Sistemas de Informação e trabalho com dados. Meus projetos passam por análise de dados, desenvolvimento web e Android, com interesse em IA aplicada a problemas do dia a dia.

Gosto de acompanhar o produto inteiro: entender o problema, organizar os dados e construir uma interface que faça sentido para quem usa. Dou atenção tanto ao visual quanto ao que acontece por trás dele — clareza, consistência e dados bem cuidados fazem parte da mesma entrega.

## Projetos

- **[Trilha](https://github.com/alzolansk/trilha)** — Planejamento de viagens em grupo, reunindo roteiro, documentos, gastos e diário. Desenvolvido com Next.js, TypeScript e Supabase.
- **[FinAI](https://github.com/alzolansk/finai-android)** — Projeto de finanças pessoais para Android, com foco em organização financeira e clareza nas informações. Desenvolvido com Kotlin, Jetpack Compose e Room.
- **[Where You Watch](https://github.com/alzolansk/where-to-watch)** — Aplicação web para descobrir onde assistir a filmes, com integração à API do TMDB.
- **[Sentiment Analysis — Tweets](https://github.com/alzolansk/sentiment-analysis-tweets)** — Análise de sentimentos em textos, com processamento de linguagem natural e visualização de dados.

## Tecnologias

**Dados e BI:** Python, Pandas, SQL, Power BI, DAX e Excel.  
**Web:** JavaScript, TypeScript, React, Next.js e Supabase.  
**Android:** Kotlin, Jetpack Compose e Room.  
**IA e integrações:** APIs de modelos de linguagem, análise de sentimentos e automação.

## Como trabalho

Aprendo construindo e revisando. Uso IA no desenvolvimento, com atenção às decisões de produto, à revisão e à validação do resultado. Prefiro soluções que sejam úteis, tenham uma interface bem resolvida e funcionem além da demonstração.
